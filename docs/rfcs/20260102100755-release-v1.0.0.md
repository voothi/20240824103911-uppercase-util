### Analytics & Decisions
- **Clipboard Utility Design**: Following the pattern of focused, single-purpose utilities. The tool is designed to be invoked manually or via automation (like AutoHotkey) to transform clipboard content to uppercase.
- **Text Cleaning Logic**:
  - **Case Normalization**: Core functionality is converting text to uppercase.
  - **HTML Removal**: Uses regex to strip tags, ensuring that text copied from rich sources is cleaned for plain-text use.
  - **Newline Handling**: Implements a specific rule to join lines (`\n(?!\s)`) which effectively flattens text while respecting intentional paragraph breaks.
- **Portability**: The tool is built using Python and can be converted to a standalone executable using PyInstaller, allowing for use without a Python environment.
- **Consistency**: Ensuring compatibility with the project ecosystem by providing clean, uppercase output.
